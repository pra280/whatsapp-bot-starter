🤖 WhatsApp Bot Starter

Starter bot WhatsApp sederhana menggunakan Node.js dan Baileys.

✨ Fitur

- ".menu" — Menampilkan daftar perintah.
- ".ping" — Mengecek respons bot.
- ".info" — Menampilkan informasi bot.

📦 Persyaratan

- Node.js
- npm
- WhatsApp untuk menghubungkan bot.

🚀 Cara Menjalankan

1. Clone repository ini.

2. Masuk ke folder proyek.

3. Instal dependensi:
   
   "npm install"

4. Jalankan bot:
   
   "npm start"

5. Ikuti petunjuk autentikasi WhatsApp yang tersedia di terminal.

⚠️ Catatan

Jangan mengunggah file sesi autentikasi atau membagikan kode QR dan kredensial akun WhatsApp kepada orang lain.
